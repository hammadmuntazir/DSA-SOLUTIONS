# Data Structures and Algorithms Solutions

A personal collection of coding-problem solutions, primarily focused on arrays and strings.

## Topics represented

- Array traversal, searching, rotation, and duplicate removal
- Missing/single/largest/second-largest element problems
- String frequency, anagrams, common prefixes, and transformations
- Additional exercises in the `array/` and `strinngs/` folders

## Run a solution

Most root-level exercises are individual Python scripts. For example:

```bash
python Array_p12_largestElement.py
```

Each file is a standalone practice solution; inputs and expected outputs may differ by exercise. Review the code before assuming all problems use the same interface.

## Goal

Use this repository to demonstrate problem-solving practice. It is separate from my main Data Engineering portfolio, which focuses on Python pipelines, SQL, data warehouses, and PySpark.
